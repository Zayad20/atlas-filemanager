# Security policy

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Use GitHub's private reporting: **Security → Report a vulnerability** on this repository, or email **support@modhyt.org** with the subject `Atlas security`.

Include the Atlas version, your Windows version, and steps to reproduce. We aim to acknowledge reports within 5 business days and will credit you in the release notes if you wish.

## Supported versions

Atlas is in alpha. Only the latest release receives security fixes.

## Scope

In scope: the Atlas application, its extension host and sandbox, file operations, archive and preview handling, license activation, and the update mechanism.
Out of scope: vulnerabilities in third-party software we do not ship, and social-engineering attacks.
