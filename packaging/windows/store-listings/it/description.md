# Atlas Gestore file

**Atlas Gestore file** è un gestore di file desktop di nuova generazione sviluppato interamente in Rust per offrire una velocità senza precedenti, un'estrema fluidità a oltre 60 FPS e un multitasking potente ed efficiente. Progettato come alternativa moderna a Esplora file e ai file manager tradizionali, Atlas unisce un'estetica raffinata alle prestazioni avanzate richieste dai professionisti.

Che tu stia navigando in vasti progetti di sviluppo software, organizzando librerie multimediali ad alta risoluzione, analizzando lo spazio su disco o gestendo i tuoi documenti quotidiani, Atlas offre la velocità, la chiarezza e il controllo totale di cui hai bisogno.

---

### Funzionalità principali

#### ⚡ Prestazioni native ad altissima velocità
Sviluppato interamente in Rust con rendering nativo accelerato tramite GPU, Atlas elimina rallentamenti e latenze nell'interfaccia. Goditi un avvio istantaneo anche a freddo, zero ritardi di indicizzazione e uno scorrimento impeccabile attraverso cartelle contenenti decine di migliaia di file, il tutto con un consumo di memoria eccezionalmente contenuto.

#### 📑 Schede e doppio riquadro di lavoro
Gestisci più attività contemporaneamente con la massima facilità:
- **Schede illimitate**: Apri, duplica, riordina e ripristina le schede proprio come nel tuo browser web preferito.
- **Doppio riquadro e viste divise**: Lavora con riquadri affiancati o sovrapposti per confrontare cartelle e spostare file senza dover gestire molte finestre separate.
- **Molteplici modalità di visualizzazione**: Personalizza la visualizzazione per ciascuna cartella scegliendo tra Elenco dettagliato, Griglia di miniature regolabili, Colonne a cascata (Miller) e Struttura ad albero espandibile.
- **Ereditarietà della vista**: Imposta lo stile di visualizzazione, le colonne e i criteri di ordinamento per una cartella specifica oppure applicali a tutte le sottocartelle.

#### 🔍 Ricerca istantanea e filtro in tempo reale
Non perdere mai più un file. Atlas include una ricerca indicizzata ad altissima velocità e un filtro fuzzy in tempo reale su tutte le unità con risposte immediate in pochi millisecondi. Filtra i file al volo per tipo, estensione o tag personalizzati senza alcun rallentamento del sistema.

#### 💾 Visualizzazione interattiva dello spazio e pulizia disco
Prendi il pieno controllo dello spazio di archiviazione:
- **Mappa visiva dello spazio**: Esplora mappe gerarchiche interattive (treemap) in cui le dimensioni delle aree riflettono l'effettiva occupazione del disco. Fai doppio clic per esplorare le cartelle più pesanti.
- **Pulizia intelligente del disco**: Individua in sicurezza file temporanei obsoleti, download voluminosi, cache dei browser, log e dump di arresto anomalo.
- **Verifica sicura**: Elimina definitivamente o sposta nel Cestino solo dopo aver verificato l'anteprima dettagliata degli elementi selezionati.

#### 🔒 Privacy totale e cartelle protette con crittografia
I tuoi file appartengono solo a te:
- **Zero telemetria**: L’app desktop non invia analisi di utilizzo. Le operazioni sui file locali vengono eseguite sul dispositivo. Le connessioni cloud facoltative trasferiscono file e metadati per le azioni richieste; i controlli degli aggiornamenti e i download di strumenti usano la rete.
- **Cartelle protette da crittografia (Cassaforte)**: Proteggi le cartelle riservate con password e crittografia locale robusta. Le cartelle protette rimangono completamente inaccessibili e indecifrabili da Esplora file e dagli altri profili utente finché non inserisci la password.

#### ⌨️ Tavolozza dei comandi da tastiera e scorciatoie
Progettato per garantire la massima produttività da tastiera:
- **Tavolozza dei comandi (`Ctrl+P`)**: Esegui qualsiasi comando, cambia vista, raggiungi i segnalibri o modifica le impostazioni direttamente da un riquadro di ricerca rapida.
- **Accesso rapido**: Aggiungi le tue cartelle e azioni preferite direttamente alla barra di accesso rapido per aprirle con un solo clic.
- **Scorciatoie personalizzabili**: Configura le combinazioni di tasti in base alle tue preferenze per navigare e gestire i file interamente senza mouse.
- **Rinomina in blocco ad alta velocità**: Rinomina centinaia di file simultaneamente utilizzando modelli flessibili, numerazione progressiva e sostituzione di testo con anteprima in tempo reale.
- **Anteprime avanzate integrate**: Riquadro di anteprima istantaneo per documenti Markdown, codice sorgente con evidenziazione sintattica, file PDF, immagini, audio, video e archivi compressi.
