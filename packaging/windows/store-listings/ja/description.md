# Atlas ファイルマネージャー

**Atlas ファイルマネージャー**は、妥協のない超高速動作、60+ FPS の極めて滑らかな描画、そして高度なマルチタスク性能を実現するために Rust 言語で一から設計された、Windows 向けの次世代デスクトップ ファイルマネージャーです。従来のファイル管理ツールの常識を覆し、洗練されたモダンなデザインとワークステーション級のパワフルな処理能力を融合しました。

大規模なソースコード リポジトリの探索から、大容量メディア ライブラリの整理、ストレージ容量の可視化・クリーンアップ、日々の日常的なファイル操作まで、Atlas はプロフェッショナルが求める圧倒的なスピード、明快さ、そして精密な操作性を提供します。

---

### 主な機能と特徴

#### ⚡ 圧倒的なネイティブ パフォーマンス
Rust 言語と GPU アクセラレーション（DirectX）によるダイレクト レンダリングを採用し、UI の引っかかりや遅延を徹底的に排除しました。瞬時のコールド スタート、インデックス作成待ちのない軽快な動作、数万個のファイルを含む大容量フォルダーでも滑らかに追従する 60+ FPS スクロールを、極めて低いメモリ消費量で実現しています。

#### 📑 タブと2画面分割ワークスペース
高度なマルチタスクを直感的にこなせます:
- **無制限のタブ**: ブラウザー感覚でタブを開き、並べ替え、複製し、閉じたタブを瞬時に再開。
- **2画面分割ペイン**: 左右（水平）や上下（垂直）に画面を分割。ウィンドウを行き来することなく、フォルダー間の比較やファイルのドラッグ＆ドロップ移動が可能です。
- **多彩な表示モード**: フォルダーの用途に合わせて、情報密度の高い「詳細」、視覚的な「サムネイル グリッド」、無駄のない「一覧」、Finder スタイルの「列 (Miller)」、階層構造を把握しやすい「ツリー」を切り替え可能。
- **フォルダー表示の継承**: フォルダーごとに個別の表示モードや並び順を設定することも、サブフォルダー全体に一括継承させることも自由自在です。

#### 🔍 瞬時のファイル検索とリアルタイム フィルター
必要なファイルを二度と見失いません。ミリ秒単位で応答する高速インデックス検索とあいまい（Fuzzy）マッチングにより、膨大なドライブの海から瞬時にファイルを特定できます。拡張子、ファイルの種類、カスタム タグによるリアルタイムの絞り込みにも対応しています。

#### 💾 インタラクティブなディスク領域可視化とクリーンアップ
PC のストレージ容量を完全にコントロール:
- **ビジュアル ディスク マップ**: フォルダーやファイルの実際の専有容量をブロックの面積で表現するインタラクティブなツリーマップを採用。肥大化したサブフォルダーをダブルクリックで直感的に掘り下げられます。
- **インテリジェントなクリーンアップ**: 7日以上前の不要な一時ファイル、ブラウザー キャッシュ、開発環境キャッシュ（npm、pip、cargo、yarn など）、クラッシュ ダンプを安全に検出。
- **安心の事前プレビュー**: 削除対象のファイル一覧と復元不可の警告を事前に確認可能。ごみ箱への移動または完全削除を用途に応じて選択できます。

#### 🔒 プライバシー最優先の設計と暗号化保管庫
あなたのデータはあなただけのものです:
- **テレメトリ（利用状況送信）ゼロ**: デスクトップアプリは使用状況の分析データを送信しません。ローカルファイルの操作は端末上で実行されます。任意のクラウド接続では、要求した操作に必要なファイルやメタデータが転送されます。更新の確認や追加ツールのダウンロードにはネットワークを使用します。
- **暗号化プライベート フォルダー**: パスワードで保護された強力なローカル暗号化保管庫を作成可能。ロックされたフォルダーの内容は、パスワードでロック解除されるまでエクスプローラーや他のユーザー プロファイルからも完全に保護され、閲覧できません。

#### ⌨️ パワーユーザー向けコマンド パレットとキーボード操作
キーボードから手を離さずに、あらゆる作業を最短ステップで完了:
- **コマンド パレット (`Ctrl+P`)**: 単一の入力バーから、すべてのコマンド実行、設定変更、移動先ジャンプ、テーマ切り替えをすばやく呼び出し可能。
- **クイック アクセスへのピン留め**: よく使うアクションをツールバーにワンクリックでピン留め。
- **高度な一括リネーム**: 検索・置換、規則的な連番付与、複数行マルチカーソル編集により、大量のファイル名を一瞬で整理。
- **充実の内蔵プレビュー**: Markdown、シンタックス強調表示付きソースコード、PDF、高解像度画像、音声、動画、ZIP アーカイブの内容を外部アプリを開かずに即座にプレビュー。
