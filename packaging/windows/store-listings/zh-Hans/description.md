# Atlas 文件管理器 — 专为现代 Windows 打造的极速文件体验

告别传统文件资源管理器的卡顿、臃肿与低效。**Atlas 文件管理器**采用 Rust 语言与现代 GPU 硬件加速技术打造，为您带来丝滑流畅、功能强大的全新文件管理体验。无论您是处理海量代码的开发者、管理庞大素材的设计师，还是追求桌面整洁与高效的日常用户，Atlas 都能让您的工作流如虎添翼。

---

### 🌟 核心特色与亮点

#### ⚡ 极致性能，瞬间响应
* **GPU 硬件加速渲染**：采用现代渲染架构，支持流畅滚动与动画；实际帧率取决于设备、目录内容和工作负载。
* **快速启动与目录浏览**：通过按需加载和虚拟化处理大型目录；实际启动和加载时间取决于设备与存储条件。
* **低内存占用与高能效**：精雕细琢的系统底层资源调度，长时间运行依然轻盈敏捷。

#### 🗂️ 现代化多标签页与多窗格拆分
* **灵活的多标签页浏览**：告别桌面上混乱散落的资源管理器窗口，像使用现代浏览器一样高效管理多个工作路径。
* **水平与垂直双窗格（Dual-Pane）**：一键水平或垂直拆分视图，左右/上下对照浏览，轻松实现跨目录对比与文件拖放。
* **均分与空间平衡**：智能均分同级或全部窗格空间，多任务处理清晰有序。
* **米勒分栏（Miller Columns）与树状视图**：提供类似 macOS Finder 的级联分栏视图及可折叠文件夹树，层级结构一览无余。

#### 🔍 毫秒级即时搜索与模糊查找
* **全局快速跳转（Go to）**：按下快捷键输入字母碎片，即可毫秒级定位目标文件夹与文件，支持拼音匹配与模糊查询。
* **内置全文内容检索（Grep）**：无需打开第三方工具，直接在文件管理器内快速检索文件内部文本内容。
* **实时目录筛选**：在当前文件夹中键入即可瞬时过滤匹配项，查找文件从未如此轻松。

#### 📊 交互式磁盘空间分析与安全清理
* **直观的可视化矩形树图（Treemap）**：方块面积直观呈现文件与文件夹占用大小，层层钻取深入探索存储空间分布。
* **快速 NTFS MFT 深度扫描**：支持基于 NTFS 索引的瞬时磁盘扫描，瞬间掌握全盘存储状况。
* **清理前逐项审查**：识别可清理的临时文件和缓存，先审查待删清单，再选择回收或删除。请保留重要文件的独立备份。

#### 🔒 隐私与本地加密
* **本地操作与可选网络功能**：桌面应用不会发送使用分析数据。本地文件操作在设备上执行。可选云连接会传输请求操作所需的文件和元数据；更新检查及工具下载需要使用网络。
* **密码保护私密文件夹（Vault）**：使用密码保护的本地加密。请妥善保管密码并备份重要数据。Windows 文件系统挂载需要单独安装可选的 WinFsp 集成。
* **解锁与锁定**：输入密码打开私密文件夹，使用会话栏锁定。解锁后通过其他应用打开或复制出的文件可能保留未加密副本。

#### 🛠️ 生产力瑞士军刀
* **独创径向轮盘转换工具**：在文件上唤起轮盘菜单，原位转换图像、视频、音频和文档格式，原始文件完好无损。
* **强大批量重命名**：支持多光标同步编辑、前后缀追加、查找替换及序列编号插入，文件整理快如闪电。
* **快捷键全键盘驱动**：支持全局命令面板（Command Palette），并专为极客提供完整的 Vim 导航模式（hjkl 键盘流）。
* **多云存储统一挂载**：直接连接 WebDAV、OneDrive、Google Drive、S3、SFTP 等云存储服务，在本地以统一体验轻松管理。
* **现代个性化美学**：优雅精致的毛玻璃（Mica / Acrylic）视觉风格，支持自定义主题以及兼容 VS Code 的精美文件图标包。
