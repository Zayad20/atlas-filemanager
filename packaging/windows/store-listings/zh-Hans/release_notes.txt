【全新特性与更新亮点】

1. 完整简体中文本地化：
   - 现已提供官方简体中文（zh-Hans / zh-CN）完整支持，100% 覆盖全部界面词条与提示。
   - 严格遵循 Microsoft Windows 官方简体中文人机交互指南与系统标准术语规范。

2. 全新功能使用指南：
   - 新增逐步功能导览指南，助您快速熟悉极速搜索、双窗格拆分、磁盘空间分析、密码保护私密文件夹等强大工具。

3. CJK 中文显示与排版优化：
   - 针对 Windows DirectWrite 与 GPUI 渲染引擎深度优化中文字体回退机制（完美回退至微软雅黑 / Microsoft YaHei）。
   - 优化中英文字符等宽与全角半角混排，改善详细信息列表分栏自适应排版。

4. 核心功能与性能提升：
   - 增强双窗格与多标签页之间的文件拖拽交互，操作更加平滑顺畅。
   - 优化 NTFS 卷快速 MFT 索引读取性能，大幅缩短磁盘空间分析扫描耗时。
   - 升级批量重命名引擎，提供更直观的多光标编辑体验与实时命名冲突预警。
   - 修复多项已知的界面渲染与操作边界异常，进一步提升运行稳定性与内存效率。
