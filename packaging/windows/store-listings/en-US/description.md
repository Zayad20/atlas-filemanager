# Atlas File Manager

**Atlas File Manager** is a next-generation desktop file manager built from scratch in Rust to deliver unprecedented speed, fluid 60+ FPS responsiveness, and powerful multitasking. Engineered as a modern replacement for traditional file managers, Atlas combines sleek desktop aesthetics with workstation-grade performance.

Whether you are navigating massive codebases, organizing creative media libraries, analyzing drive capacity, or managing day-to-day files, Atlas delivers the speed, clarity, and control you need.

---

### Key Capabilities

#### ⚡ Blazing-Fast Native Performance
Built entirely in Rust with native GPU-accelerated rendering, Atlas eliminates sluggishness and UI lag. Enjoy instant cold startup, zero indexing delays, and silky-smooth scrolling through directories containing tens of thousands of files—all while maintaining an exceptionally light memory footprint.

#### 📑 Tabs & Dual-Pane Workspaces
Multitask with effortless precision:
- **Unlimited Tabs**: Open, duplicate, reorder, and restore tabs just like in a modern web browser.
- **Dual Panes & Splits**: Work with side-by-side or stacked split panes to move and compare files across folders without juggling multiple windows.
- **Multiple View Modes**: Tailor your perspective per folder with high-density Details, adaptive thumbnail Grids, or multi-level Miller Columns.
- **Folder View Inheritance**: Configure view styles, columns, and sorting per folder or propagate them across entire subfolder trees.

#### 🔍 Instant Search & Real-Time Filtering
Never lose a file again. Atlas features instant indexed file search and fuzzy filtering across drives with millisecond response times. Filter files on the fly by type, extension, or custom tags without slowing down your system.

#### 💾 Interactive Disk Space Visualizer & Cleanup
Take complete control of your storage:
- **Visual Space Lens**: Explore interactive hierarchical space maps (treemaps) where block sizes reflect actual drive usage. Double-click to zoom into large subfolders.
- **Intelligent Storage Cleanup**: Safely identify obsolete temporary files, oversized downloads, browser caches, and crash dumps.
- **Safe Review**: Permanently delete or move unwanted items to the Recycle Bin with full preview confirmation before any changes take place.

#### 🔒 Privacy-First Architecture & Encrypted Vaults
Your files belong strictly to you:
- **Zero Telemetry**: The desktop app sends no usage analytics. Local file operations run on your device. Optional cloud connections transfer files and metadata for the actions you request; update checks and optional tool downloads use the network.
- **Private Encrypted Vaults**: Protect sensitive folders with password-authenticated local encryption. Locked vaults remain completely opaque and unreadable across other user profiles and File Explorer until unlocked with your password.

#### ⌨️ Power-User Keyboard Palette & Shortcuts
Designed for maximum hands-on-keyboard efficiency:
- **Command Palette (`Ctrl+P`)**: Run any command, toggle views, jump to bookmarks, or change settings instantly from a single fuzzy-searchable prompt.
- **Quick Access Pinning**: Pin your most critical actions directly to the quick header for single-click execution.
- **Customizable Keybindings**: Adjust hotkeys to fit your muscle memory, including full keyboard navigation.
- **High-Speed Batch Renaming**: Rename hundreds of files simultaneously using customizable patterns, sequence numbers, and text replacement rules.
- **Integrated Previews**: Built-in instant preview inspector for Markdown, syntax-highlighted source code, PDFs, high-resolution images, audio, video, and archives.
