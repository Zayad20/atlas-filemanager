Atlas File Manager 0.1.0 — Перший випуск

Ласкаво просимо до першого офіційного випуску Atlas File Manager для Windows!

Головні особливості:
• Блискавична швидкодія: Створено з нуля мовою Rust із нативним GPU-прискоренням для надзвичайної плавності 60+ FPS та мінімального споживання пам'яті.
• Вкладки та двопанельний режим: Організація робочого процесу за допомогою необмежених вкладок і розділених панелей (поруч або одна над одною).
• Гнучкі режими перегляду: Детальна таблиця, адаптивна сітка ескізів та каскадні стовпці Міллера під будь-які завдання.
• Миттєвий пошук і перехід: Нечітке фільтрування файлів на дисках у реальному часі з мілісекундним відгуком.
• Інтерактивний аналізатор диска: Наочна деревоподібна карта дискового простору для швидкого виявлення великих файлів та безпечного видалення непотрібних даних.
• Захищені приватні папки: Локальне шифрування папок із захистом паролем, що гарантує надійну ізоляцію особистих файлів.
• Палітра команд швидкого доступу: Виклик палітри (Ctrl+P) і настроювані комбінації клавіш для швидкої роботи без миші.
• Швидкісне пакетне перейменування: Потужний інструмент групового перейменування з підтримкою послідовної нумерації, пошуку/заміни та попереднього перегляду.
• Вбудований інспектор перегляду: Миттєвий огляд PDF, зображень, аудіо, відео, розмітки Markdown, вихідного коду з підсвічуванням синтаксису та архівів.
• Повна українська локалізація: Досконалий переклад усіх інтерфейсних елементів відповідно до офіційних стандартів української версії Windows.
