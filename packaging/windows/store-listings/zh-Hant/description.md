# Atlas 檔案總管

**Atlas 檔案總管** 是一款使用 Rust 從零打造的次世代桌面檔案管理工具，具備前所未有的極致速度、絲滑流暢的 60+ FPS 操作手感與強大的多工作業能力。專為取代傳統笨重、延遲的檔案管理員而設計，Atlas 將現代簡約的美學與工作站等級的頂級效能完美融合。

無論您是在處理包含數萬個檔案的龐大程式碼專案、整理大量高解析度相片與影片素材、深度分析磁碟容量佔用，或是日常檔案整理，Atlas 都能為您提供最極速、清晰且精準的操控體驗。

---

### 核心特色

#### ⚡ 極致迅捷的原生效能
完全以 Rust 語言打造，並採用本機 GPU 硬體加速渲染技術，徹底告別傳統介面的卡頓與延遲。享受隨開即用的秒速冷啟動、零延遲目錄讀取，即便捲動包含數萬個檔案的資料夾亦能保持如絲般順暢，同時維持極為輕巧的記憶體佔用。

#### 📑 分頁瀏覽與雙窗格工作區
為高效率多工作業量身打造：
- **無限制分頁**：如同現代瀏覽器般輕鬆開啟、複製、拖曳重排與還原分頁。
- **雙窗格與分割檢視**：支援左右並排或上下堆疊的分割窗格，免去切換視窗的繁瑣，讓資料夾間的檔案比對與搬移一氣呵成。
- **多種檢視樣式**：依不同資料夾自由套用高資訊密度的「詳細資料」、自適應縮圖「網格」、或經典階層式「Miller 欄 (米勒直欄)」。
- **資料夾檢視繼承**：個別資料夾自訂檢視外觀，或一鍵套用至所有子資料夾樹狀目錄。

#### 🔍 即時搜尋與即打即找篩選
再也不會遺失任何檔案。Atlas 內建毫秒級回應的索引搜尋與模糊篩選器。無需等待，隨打即時跨磁碟機篩選，並能依類型、副檔名或標籤迅速縮小搜尋範圍。

#### 💾 互動式磁碟空間視覺化與清理
全面掌控硬碟儲存空間：
- **視覺化空間地圖 (Treemap)**：透過互動式樹狀空間分佈圖探索磁碟，區塊大小如實反映佔用空間。按兩下即可深入查看龐大子目錄。
- **智慧型磁碟清理**：精準掃描並安全揪出已無效的暫存檔案、超大下載檔、瀏覽器快取與當機傾印檔案。
- **安全審查確認機制**：在執行任何清理動作前提供完整預覽確認，可選擇將檔案移至資源回收筒或永久刪除，絕不誤刪個人珍貴資料。

#### 🔒 堅持隱私優先與加密保險箱
您的檔案只屬於您自己：
- **零遙測 (Zero Telemetry)**: 桌面應用程式不會傳送使用分析資料。本機檔案操作在你的裝置上執行。選用的雲端連線會根據你的操作要求傳輸檔案與中繼資料；檢查更新及下載選用工具需要使用網路。
- **私密加密保險箱**：為敏感機密資料夾提供高強度密碼保護與本機加密。鎖定狀態下，內容在其他使用者設定檔或傳統檔案總管中完全無法窺視與讀取，唯有憑密碼解鎖方能存取。

#### ⌨️ 效率鍵盤操作與命令面板
專為鍵盤愛好者打造的極致流暢操作：
- **命令面板 (`Ctrl+P`)**：只需一個熱鍵呼叫命令面板，模糊搜尋即可執行所有功能、切換檢視、跳轉書籤或更改設定。
- **快速存取釘選**：將最常用的資料夾或功能動作釘選至頂部快速存取列，一鍵迅速調用。
- **高自訂性快速鍵**：可完全依照個人肌肉記憶自訂快速鍵設定。
- **高效率批次重新命名**：支援多重游標同時編輯、自訂樣式、自動流水號與規則運算式文字取代，一口氣整理數百個檔案。
- **全能即時預覽窗格**：內建極速預覽檢視窗，即時預覽 Markdown、程式碼語法標亮、PDF、高解析度圖片、音訊、影片與壓縮檔。
