# Atlas 파일 관리자 (Atlas File Manager)

**Atlas 파일 관리자**는 현대적인 데스크톱 사용자를 위해 Rust로 처음부터 새롭게 구축된 차세대 네이티브 파일 관리자입니다. 유려한 디자인, 60+ FPS의 버벅임 없는 반응성, 강력한 멀티태스킹 기능을 결합하여 기존 파일 탐색기를 뛰어넘는 쾌적한 작업 환경을 제공합니다.

대규모 코드베이스를 다루는 개발자, 방대한 미디어 라이브러리를 정리하는 크리에이터, 드라이브 용량을 관리하는 파워 유저, 일상적인 파일을 다루는 일반 사용자까지, Atlas는 최고의 속도와 정밀한 제어력을 선사합니다.

---

### 주요 핵심 기능

#### ⚡ 네이티브 초고속 성능
Rust 언어의 메모리 안전성과 GPU 하드웨어 가속 렌더링을 바탕으로 지연과 버벅임을 완전히 제거했습니다. 프로그램 실행 즉시 열리는 빠른 실행 속도, 수만 개의 파일이 포함된 대규모 디렉터리에서도 부드러운 60+ FPS 스크롤링, 극도로 가벼운 시스템 리소스 점유율을 경험할 수 있습니다.

#### 📑 탭 및 듀얼 창 분할 워크스페이스
창을 여러 개 띄우며 헤맬 필요 없이 단 하나의 창에서 모든 멀티태스킹을 완성하세요.
- **무제한 탭**: 웹 브라우저처럼 탭을 자유롭게 열고, 복제하고, 재정렬하고, 복원할 수 있습니다.
- **듀얼 창 및 분할 보기**: 화면을 가로 또는 세로로 자유롭게 분할하여 두 개 이상의 폴더를 나란히 비교하고 파일을 즉시 끌어다 놓아 이동하거나 복사할 수 있습니다.
- **다양한 파일 보기 모드**: 상세한 파일 정보를 볼 수 있는 '자세히 보기', 시각적인 '아이콘(썸네일 그리드)', macOS Finder 스타일의 '밀러 컬럼(열 보기)', 직관적인 계층 구조의 '트리 보기'를 지원합니다.
- **폴더별 개별 보기 설정**: 폴더마다 최적화된 보기 모드와 정렬 방식을 기억하며, 하위 폴더에 설정을 상속할 수도 있습니다.

#### 🔍 인스턴트 검색 및 실시간 필터링
원하는 파일을 찾는 데 1초도 낭비하지 마세요. 밀리초 단위로 결과를 찾아내는 고성능 색인 검색과 실시간 퍼지 필터링으로 드라이브 전체 또는 현재 폴더 내의 파일을 즉시 찾아냅니다. 파일 형식, 확장자, 태그를 기준으로 빠르게 필터링할 수 있습니다.

#### 💾 대화형 디스크 공간 시각화 및 안전 정리
디스크 저장 공간을 손쉽고 안전하게 관리하세요.
- **시각적 트리맵 공간 렌즈**: 폴더와 파일의 실제 용량에 비례하는 인터랙티브 타일 지도를 통해 디스크를 차지하는 요소를 한눈에 파악할 수 있습니다. 두 번 클릭하여 하위 폴더로 깊숙이 탐색하세요.
- **스마트 임시 파일 정리**: 7일 이상 지난 불필요한 사용자 임시 파일, 브라우저 캐시, 크래시 덤프, 개발 캐시(npm, pip, cargo 등)를 안전하게 탐지합니다.
- **철저한 사전 검토**: 사용자의 사전 확인 없이 파일이 삭제되지 않으며, 영구 삭제 또는 휴지통 이동을 선택하여 안전하게 디스크 공간을 확보할 수 있습니다.

#### 🔒 개인정보 우선 아키텍처 및 암호화 비공개 금고
사용자의 데이터는 온전히 사용자만의 것입니다.
- **원격 측정(Telemetry) 0%**: 데스크톱 앱은 사용 통계를 전송하지 않습니다. 로컬 파일 작업은 기기에서 실행됩니다. 선택적 클라우드 연결은 요청한 작업에 필요한 파일과 메타데이터를 전송하며, 업데이트 확인과 추가 도구 다운로드는 네트워크를 사용합니다.
- **비밀번호 보호 암호화 금고**: 민감한 폴더를 비밀번호 기반의 로컬 암호화로 안전하게 잠글 수 있습니다. 잠긴 금고는 비밀번호를 입력하여 잠금을 해제하기 전까지 파일 탐색기나 다른 사용자 프로필에서 내용을 절대 열람할 수 없습니다.

#### ⌨️ 파워 유저를 위한 키보드 중심 환경
마우스 없이 키보드만으로 모든 조작을 신속하게 완료하세요.
- **명령 팔레트 (`Ctrl+P`)**: 명령 실행, 보기 전환, 설정 변경, 즐겨찾기 이동을 단 하나의 검색창에서 즉시 실행합니다.
- **일괄 이름 바꾸기 (Batch Rename)**: 정규식/패턴, 번호 매기기, 찾기 및 바꾸기 규칙을 활용하여 수백 개의 파일 이름을 순식간에 변경할 수 있으며, 변경 전 실시간 충돌 검증을 제공합니다.
- **풍부한 내장 파일 미리 보기**: 소스 코드(구문 강조), 마크다운, PDF 문서, 고해상도 이미지, 오디오, 비디오, ZIP/압축 파일 내용을 별도의 프로그램 실행 없이 즉시 확인합니다.
- **사용자 맞춤 프로필 및 테마**: 업무, 개발, 개인용 등 상황에 따라 독립된 테마, 사이드바 즐겨찾기, 확장 설정을 전환할 수 있습니다.
